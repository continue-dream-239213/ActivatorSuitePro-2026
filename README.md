### How often is OmniPatch updated?

We aim to release an update within 48 hours whenever a supported app releases a major update that might affect patch functionality.

### Does this require an internet connection?

No, the patcher works completely offline after download. An internet connection is only needed to download the initial archive and check for updates.

### Will my account get banned?

OmniPatch modifies local files only and does not interact with servers, so account bans are highly unlikely. Use at your own discretion and review app terms.

### Can I use this on macOS or Linux?

OmniPatch is designed exclusively for Windows desktop applications. There are no current plans for other operating systems.

### What if the patcher flags my anticomponent?

Some security tools may flag patchers generically. Our releases are code-signed and scanned, but you may need to add an exception for 'omnipatch.exe'.

### How do I revert changes if something goes wrong?

The patcher includes a 'Restore Backup' feature that uses automatically created backups to revert the original application files with one click.
